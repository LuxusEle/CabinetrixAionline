📋 Installation Instructions

  • 1
    Download either the CabinexAI_v4.rbz or BoardSash_v2.rbz file using the buttons above.
  • 2
    In SketchUp, go to Window → Extension Manager → Install Extension and select the downloaded .rbz file.
  • 3
    Click Yes when prompted to install the extension from a downloaded source.
  • 4
    After installation, find Plugins → Cabinex AI → Kitchen Designer in the menu bar.
  • 5
    On first launch, enter your License Token Key (issued from this admin panel).
    ⚠️ Each licensed studio requires a valid token. Generate tokens from the License Tokens tab above.
