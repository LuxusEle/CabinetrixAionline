CABINET CONSTRUCTION + DESIGN LEARNING LIBRARY
==============================================

Purpose
-------
A curated set of one-click shortcuts to kitchen, wardrobe and professional
cabinetmaking construction manuals.

RECOMMENDED STUDY ORDER
-----------------------
1. Fabricating Cabinets Learner Guide
   - Board materials
   - Cutting and edging
   - Frameless cabinet construction
   - System 32
   - Plinths
   - Doors and drawers
   - Assembly

2. IKEA METOD Base Cabinet Assembly
   - Exploded carcass construction
   - Cam/dowel connections
   - Back panel
   - Suspension hardware
   - Assembly sequence

3. IKEA METOD Kitchen Installation Guide
   - Setting out a room
   - Rail positioning
   - Leveling and aligning cabinets
   - Worktop/site sequence

4. IKEA METOD Cabinets Planning Guide
   - Base, wall and tall cabinet design
   - Sink/cooker/corner layouts
   - Modular planning

5. IKEA PAX Wardrobe Assembly
   - Wardrobe carcass
   - Panel assembly
   - Back fixing
   - Installation

6. IKEA PAX + KOMPLEMENT Planning Guide
   - Wardrobe widths/depths/heights
   - Hanging zones
   - Shelving/drawers
   - Internal planning

7. BLUM / GRASS / HETTICH
   - Hinges
   - Drawer runners
   - System 32 drilling
   - Door overlays
   - Drawer deductions
   - Lift systems
   - Sliding wardrobe doors

8. KESSEBOHMER
   - Tall pull-outs
   - Corner systems
   - Pantry mechanisms
   - Internal storage engineering

HOW TO USE
----------
Windows:
Double-click any .url file. It opens the manufacturer's/current source page
or PDF in your browser.

Suggested learning target:
Understand the BOX first:
    carcass -> back -> plinth -> fixing -> door -> hinge -> drawer -> hardware

Then learn DESIGN:
    standard modules -> fillers -> corners -> appliances -> ergonomics

Then learn PRODUCTION:
    panel formulas -> cut list -> drilling -> CNC -> edging -> assembly.

Important:
These shortcut files do not contain or redistribute the third-party manuals.
They point directly to the publishers/manufacturers so you can download the
latest available copies from the original source.
